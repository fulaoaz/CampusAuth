# 界面设计与交互约定

CampusAuth 使用 Fluent 2 与 Fluent UI React v9。桌面和服务器共享中文 React 界面：桌面经 Tauri IPC 调用 Rust 核心，服务器经同源 HTTP API 管理。

## 页面与状态

主要页面包括网络连接、账号管理、自动重连、电源计划、设置与关于。侧栏可以调宽和收起，手机端使用独立导航展开状态。

首页优先显示网络状态、当前账号、连接操作、自动重连开关与最近错误。互联网状态和门户会话分别表达；仅能访问互联网时，不据此宣称门户已经认证。无响应保留未知状态。

账号默认按添加顺序尝试，也支持搜索、拖动排序与上下调整。停用账号会跳过；成功连接不改变账号保存顺序。需要断开现有会话的手动账号切换先确认。

## 色彩、字体和大小

浅色以冷白、石墨灰和克制的青绿色为主：画布 `#f5f7fa`、正文 `#192d3d`、品牌 `#087e84`。深色使用深石板灰表面，保留状态颜色和文字对比。

中文使用随包提供的 Noto Sans SC；西文优先使用设备上的 Segoe UI Variable，并保留本地字体回退。界面不依赖在线字体或图标请求。

文字大小是用户偏好：默认 15，可在 13–20 范围内调整，提供紧凑、标准、大号、特大和恢复默认入口。文字与控件采用相对尺寸及 Fluent 主题 token 同步适配；偏好保存在当前设备，重开后保留。

布局应覆盖常规桌面和 390px 手机宽度，在最大文字设置下保留表单、向导按钮和操作入口。支持键盘焦点、表单校验及减少动画偏好。

## 桌面窗口

原生系统标题栏关闭，最小化、最大化 / 还原和关闭按钮整合在应用顶部。顶部空白区域使用 Tauri 拖动区域，支持拖动与双击切换最大化；交互控件不应触发拖动。

首次关闭窗口时说明托盘行为。关闭到托盘后自动重连继续运行；托盘的“退出 CampusAuth”结束应用和后台。系统托盘不可用时保留可见入口，避免应用隐藏后无法重新打开。开机自启默认关闭。

## 首次使用与系统操作

首次向导按选择学校、添加账号、运营商服务、测试连接、自动重连的顺序进行。重连在最后一步单独确认，默认关闭；可以稍后配置。

电源计划默认关闭，先预览后明确授权应用。权限不足时说明待应用方案，保留原生效配置；取消倒计时只影响本次动作。

诊断导出先展示范围，随后进入下载或原生保存对话框。更新检查由用户主动执行。关于页显示作者 fulao、个人博客和项目入口。

UI 偏好可以保存在本机浏览器存储中，校园网密码、管理密码和会话令牌不写入此存储。
